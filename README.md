# ManejoEventoJavaFX

Proyecto desarrollado en Java utilizando JavaFX y Maven para la práctica del manejo de eventos en interfaces gráficas de usuario.

## Descripción

La aplicación está orientada al aprendizaje del manejo de eventos en JavaFX, permitiendo interactuar con distintos componentes gráficos como botones y otros controles.

El objetivo principal es comprender cómo responder a acciones del usuario dentro de una interfaz gráfica mediante eventos en JavaFX.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven

## Requisitos

- JDK 17 o superior
- Maven instalado
- IDE compatible con JavaFX (IntelliJ IDEA, Eclipse o NetBeans)
